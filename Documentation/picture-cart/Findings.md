# Findings - Picture Cart

## 2026-10-03

- Search shows family question decks (Nosh, Little Talks, Questions for Grandma), visual schedules (Now and Next, Pictalk), and bingo callers already cover those jobs.
- Picture Cart uses twelve original aisle tiles plus a typed item. Nothing is downloaded. Text size and the list are stored under `picture-cart-v1` on the device.
- Stack is Expo SDK 57. JavaScript is enough; the app does not need a framework Expo would fight.
