# Plan - Picture Cart

## Goal

Ship a free offline picture grocery list for kids, families, and seniors.

## Approach

1. Confirm App Store Connect has no rejected app waiting.
2. Build Picture Cart in Expo: picture tiles, a one-item shop mode, a bag checklist, and three text sizes. The list stays on the phone.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## 2026-10-03 later

The plan is done. Picture Cart 1.0.0 (1) is Waiting for Review.

## Why this app

Conversation-card apps, visual schedules, and bingo callers already crowd the store. A picture shopping list is a small native tool: a child can tap the apple, a grandparent can use extra-large type, and the family walks the store one item at a time.
